# Механика Кофе

Многостраничный сайт кофейни в Брянске, выполненный для контрольной работы № 1 по HTML и CSS.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта». Сайт кофейни с кофейной картой, карточкой напитка, заявкой и адресами филиалов.

## Страницы

- `index.html` — главная страница с преимуществами, популярными напитками и переходом к адресам;
- `catalog.html` — карточки кофейных напитков и якорная навигация по разделам;
- `product.html` — карточка хвойной джезвы, характеристики и диалоговое окно;
- `order.html` — форма заявки на напиток и выбор филиала;
- `contacts.html` — адреса, телефоны и ссылки на маршруты.

Общие для страниц: семантическая разметка, единая навигация и внешний CSS-файл. Используются якорные ссылки, CSS-переменные, `:hover` и `:focus-visible`, Flexbox, Grid, БЭМ, таблица характеристик и `<dialog>`. JavaScript отвечает только за открытие и закрытие диалога.

## Технологии

- HTML5;
- CSS3: Flexbox, Grid, адаптивная раскладка и CSS-переменные;
- минимальный JavaScript для окна `<dialog>`;
- GitHub Pages.

## Что добавлено к базовой структуре

У сайта отдельная визуальная система и адаптивная раскладка. В кофейной карте есть разделы с переходами к категориям, на странице джезвы — таблица характеристик и окно с описанием. В форме выбирают напиток и адрес, а со страницы контактов можно позвонить или открыть маршрут до кофейни.
